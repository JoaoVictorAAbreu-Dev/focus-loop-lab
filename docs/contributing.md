# Contributing

This repository is structured for incremental changes.

## Recommended workflow

1. Create a small branch for one change.
2. Implement only the files needed for that change.
3. Run the project checks.
4. Open a pull request.
5. Merge after review.

## Quality bar

- Keep behavior simple and explicit.
- Avoid mixing refactors with feature work.
- Add tests when backend behavior changes.
- Update documentation when the user flow changes.

## Useful commands

```powershell
npm run dev
npm run build
npm run lint
npm run test:server
```
